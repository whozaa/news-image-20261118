# News Image 18 Nov 2026 — build notes (local build only)

## What this is
Entry for Make.fun bounty `news-image-20261118`: "Sum up 18 November's
world news in one image". Program writes `/output/entry.png` (1024x1024,
<=1 MiB, deterministic — two runs byte-identical).

## Files
- `entry.png` — the infographic, 1024x1024 px, 142,337 bytes.
  Generated by `generate.py` with Pillow 10.2.0, DejaVu Sans Bold/Regular.
  Drawn programmatically: no photos, no logos, no AI-generated text.
- `generate.py` — the generator that drew `entry.png`. Kept for
  transparency; it does NOT run in the sandbox (Pillow is not stdlib).
- `main.py` — the entrypoint. Python stdlib only (`os`, `shutil`).
  Copies `entry.png` next to it to `/output/entry.png`
  (or `$MAKEFUN_OUTPUT_DIR/entry.png` when set, for local testing only).
  No network, no timestamps, no randomness.

## Layout
Deep-navy header (#0F2A44) with "THE WORLD IN ONE DAY" and the
unmissable date "WEDNESDAY 18 NOVEMBER 2026". Hero: Shenzhen summit.
Right column: Gulf, Crimea Bridge. Middle row: Alaska, Ebola, Measles.
Footer: "ALSO TODAY" briefs + source line. Minimum text size 14px
(kickers/source line); body 15-16px, headlines 24-30px.

## Legibility fixes made after visual inspection
First render had text overflowing its panels (hero body hidden behind
the stat box; Gulf/Crimea second paragraphs clipped at panel edges;
Alaska body clipped; Ebola stat label truncated).
Fixed by: combining the hero body into one paragraph, removing the
skyline drawing that collided with the stat box, shortening Gulf /
Crimea / middle-row bodies to single paragraphs, reducing body type
to 15-16px (never below 14px), reducing right-column and middle-row
headlines to 24px, and shortening the Ebola stat label to
"UNDER-5S DO NOT SURVIVE". Second render was visually checked:
no clipping, no overlap, all text readable.
